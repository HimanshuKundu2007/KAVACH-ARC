SQL Injection (CWE-89)

Root Cause

Unsanitized user input `req.body.userId` is directly concatenated into the SQL query string in the authentication middleware, allowing malicious payloads to alter query logic.

Affected Location

folder src/middleware/auth.js:42

Patch Strategy

Implement parameterized queries using prepared statements. Replace string concatenation with parameter placeholders to ensure input is treated strictly as data, not executable code.
