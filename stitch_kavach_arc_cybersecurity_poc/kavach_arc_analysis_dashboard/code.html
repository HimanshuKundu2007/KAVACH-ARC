Root Cause

The function strcpy does not check the length of the input string before copying it into the fixed-size array buf[8]. Inputs exceeding 8 bytes will overwrite adjacent stack memory.

Patch Strategy

Replace strcpy with bounded strncpy. Ensure the destination buffer is explicitly null-terminated to prevent subsequent read over-runs.
